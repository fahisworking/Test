# Simple To-Do

A small to-do list web app built with plain HTML, CSS, and JavaScript. It has no dependencies or build step.

## Features

- Add, complete, and delete tasks
- Create and delete categories, and filter the list by category
- Choose a task's category when adding it, or change it later
- Clear completed tasks in the current view
- Tasks and categories are saved in the browser with `localStorage`
- Follows the system light or dark theme

## Run it

Open `index.html` in a browser.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure |
| `style.css` | Styling and theme colors |
| `script.js` | App logic and saving |
