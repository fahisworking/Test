# Simple To-Do

A small to-do list web app built with plain HTML, CSS, and JavaScript. It has no dependencies or build step.

## Features

- Add, complete, and delete tasks
- Clear all completed tasks at once
- Tasks are saved in the browser with `localStorage`
- Follows the system light or dark theme

## Run it

Open `index.html` in a browser.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure |
| `style.css` | Styling and theme colors |
| `script.js` | App logic and saving |
